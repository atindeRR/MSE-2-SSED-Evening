C. Technical Implementation Summary

This project containerizes and deploys TaskFlow, a full-stack React + Express + PostgreSQL + Redis application with automated multi-stage builds, internal networking, health-based dependency orchestration, data persistence, and an automated continuous deployment workflow.

  • Task 1 (Dockerfiles): Backend implements Node.js 20 Alpine with production dependencies only and non-root execution (UID 1000). Frontend implements a multi-stage architecture with Node.js 20-slim build stage and Nginx 1.27-alpine runtime with reverse-proxy routing and embedded healthcheck. Both Dockerfiles passed Hadolint with zero warnings.
  • Task 2 (Docker Compose): Configured taskflow custom bridge network, PostgreSQL named volume postgres_data, database initialization mount init.sql, and health checks across all four containers.
  • Task 3 & 4 (Docker Hub & Deploy Compose): Configured docker-compose.deploy.yml for zero-build image deployment using latest tags.
  • Task 5 (Persistence & Health): Verified PostgreSQL persistence by writing test records, removing the container, and recreating it without volume loss. Verified Redis restart and caching.
  • Task 6 (GitHub Actions): Automated CD workflow in .github/workflows/cd.yml with build, push, deployment verification, and integration test execution.
