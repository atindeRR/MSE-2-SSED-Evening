C. Technical Architecture & Implementation Summary

  • Frontend Containerization: Implemented multi-stage Docker build with node:20-slim build stage to compile React assets with Vite, and nginx:1.27-alpine production stage reverse-proxying API traffic to http://backend:3000.
  • Backend Containerization: Multi-stage build with node:20-alpine, strict production dependency installation (--omit=dev), running securely as non-root user USER node on port 3000.
  • Local Compose (docker-compose.yml): Orchestrates frontend, backend, postgres, and redis services over a custom bridge network (taskflow) with persistent database volume (postgres_data) and health dependencies.
  • Image-Based Deployment (docker-compose.deploy.yml): Pure image deployment using published Docker Hub images (bhavya2718/backend:latest and bhavya2718/frontend:latest) with zero local build directives.
  • CI/CD Workflow (.github/workflows/cd.yml): Automated GitHub Actions workflow on main push that builds, tags (v1 & latest), pushes 4 image tags to Docker Hub, deploys stack on runner, and executes all 12 API tests.
